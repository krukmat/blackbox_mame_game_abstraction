### ST.B1 — Implement flag + tests

**Implementation:**

In `packages/vision/trace_extractor.py`:

```python
def _entity_type_from_box(
    region: MotionBox,
    frame_width: int,
    frame_height: int,
    allow_player: bool = True,  # T10.7.B: False when player slot already claimed by ArthurTracker
) -> str:
    ratio = (region.width * region.height) / (frame_width * frame_height)
    if allow_player and ratio >= _RATIO_PLAYER:
        return "player"
    if ratio >= _RATIO_ENEMY_A:
        return "enemy_a"
    if ratio >= _RATIO_PROJECTILE:
        return "projectile"
    return "hazard"
```

In `extract_trace`, update both call sites that process `remaining_regions`:

```python
# Peek loop (disappearance detection)
remaining_peek = _regions_except_claimed(curr_stat.changed_regions, player_region_peek)
for ri, region in enumerate(remaining_peek):
    etype = _entity_type_from_box(region, frame_width, frame_height, allow_player=False)
    ...

# Main emission loop
remaining_regions = _regions_except_claimed(curr_stat.changed_regions, player_region)
for region_index, region in enumerate(remaining_regions):
    entity_type = _entity_type_from_box(region, frame_width, frame_height, allow_player=False)
    ...
```

**Regression tests** (in `packages/vision/tests/test_trace_extractor_multi.py` or new dedicated file):

1. `test_entity_type_returns_player_when_allow_player_default` — large blob, default flag → "player"
2. `test_entity_type_returns_enemy_a_when_allow_player_false` — same large blob, flag false → "enemy_a"
3. `test_entity_type_still_classifies_projectile_when_allow_player_false` — small blob, flag false → "projectile" (verify flag doesn't break smaller categories)
4. `test_extract_trace_two_player_sized_blobs_emits_one_player_one_enemy` — integration: synthetic frame with Arthur + another player-sized blob → trace has 1 `entity_id="player"` + 1 `entity_id="enemy_a_<frame>_0"`

**Files affected**: `packages/vision/trace_extractor.py`, `packages/vision/tests/test_trace_extractor_multi.py`
