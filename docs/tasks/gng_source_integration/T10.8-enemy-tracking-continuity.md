# T10.8 — Enemy Tracking Continuity (Stage 1, Screen 1)

## Status

🔲 Planned — awaiting explicit approval before implementation.

## Objective

Provide cross-frame identity continuity for non-player entities (enemies) in GNG stage 1 screen 1, so that `specs/traces/gng_trace.json` exposes a coherent per-enemy lifecycle (`spawn → motion → die`) instead of the current ephemeral frame-indexed IDs (`enemy_a_{frame}_{region_index}`). Scope is limited to walking and flying enemies that appear before the first camera scroll — zombi and crow. Boss encounters are deferred to T10.9.

## Scope

- Generalize `ArthurTracker` into a reusable `EntityTracker` keyed by `EntitySignature` (one matching algorithm, multiple per-type signatures).
- Calibrate `EnemySignature` bounds for zombi and crow via an ADR-019 picker workflow over existing `run_t10_4_01` evidence (and one complementary capture if needed).
- Replace the ephemeral `{entity_type}_{frame}_{region_index}` ID scheme with persistent `{entity_type}_{spawn_frame}_{spawn_index}` IDs allocated by the tracker.
- Emit `spawn` events only on first appearance and `die` events on gap-tolerant disappearance per enemy.
- Regenerate `specs/traces/gng_trace.json` from `run_t10_4_01` and verify against quality gates (per-enemy duration, spawn-count plausibility, no orphan spawns).
- Publish ADR-021 and update ADR-013 Known Gaps.

## Out of Scope

- Red Arremer (devil) tracking — deferred to T10.9.
- Stage 1 final boss (cyclops / "Big Men") tracking — deferred to T10.9 and requires the ADR-013 MOG2 scroll reset gap to be resolved first.
- Static hazards (graveyard plants/cactus) — no continuity required; current `_entity_type_from_box` `hazard` classification is unchanged.
- Enemy projectiles (thrown lances) — projectile work lives in T10.7.E.
- Hungarian or learned multi-object assignment — greedy nearest-neighbor with `max_frame_jump_px` ceiling is sufficient for screen 1.
- Stage 2+ camera scroll handling — ADR-013 Known Gap, deferred.
- Calibration of enemy locomotion or behavior constants in `gng_abstract_mechanics.yaml` (only `entity_event_trace` enum examples are touched; quantitative enemy mechanics belong to T12).

## Dependencies

- ✅ T10.5 — `ArthurTracker` infrastructure (the refactor preserves its public surface).
- ✅ T10.6 — OpenCV backend, multi-region `FrameDiffer`, HUD masking.
- ✅ T10.7 ST1/ST2 — `max_frame_jump_px` + `MIN_GROUND_STREAK` (the pattern is generalized in T10.8).
- 🔲 T10.7.E — projectile in-flight tracking; should land first so `EntityTracker` can subsume any structurally-compatible projectile continuity work.
- Quality-gated frames in `evidence/private/run_t10_4_01/frames/` for signature calibration (existing).

## Blocks

- T11.2 episode extractor quality — episodes built from a trace without enemy continuity contain inflated `spawn` counts and no per-enemy lifecycle.
- T12.3 encounter grammar — archetype calibration requires per-enemy motion arcs.

## Reasoning Grade

`High`

Reasoning basis:
- Cross-module impact: `arthur_tracker.py` → `entity_tracker.py` (new) → `trace_extractor.py` → `gng_trace.json` → downstream consumers (episode extractor, validation).
- Architectural refactor of one of the most-tested files in the vision layer.
- Signature calibration involves human-validated evidence interpretation (ADR-019).
- Greedy assignment edge cases (cross-paths, occlusions) require careful regression coverage.

## Risks

- **R1 — Zombi partial occlusion by player**: when Arthur attacks a zombi, the `FrameDiffer` may return a merged region. Mitigated by per-type `gap_tolerance_frames` (default 3).
- **R2 — Crow signature overlap with projectile signature**: small flying region can collide with projectile area-ratio. Mitigated by signatures taking precedence over `_entity_type_from_box` fallback.
- **R3 — MOG2 absorbs stationary zombi in grave**: pre-emergence stillness may be background-modeled. Accepted limitation; emergence motion breaks absorption.
- **R4 — Greedy ID swap on cross-paths**: two same-type enemies crossing within `max_frame_jump_px` can swap IDs. Accepted for screen 1; revisit if validation fails.
- **R5 — Refactor regression in `ArthurTracker`**: wrapper must preserve existing public API exactly. Mitigated by keeping all current tests green as a hard gate.
