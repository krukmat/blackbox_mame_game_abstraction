## Purpose

Obtain a private evidence capture of GNG gameplay with real player input so that subsequent tasks (T10.2+) have observable behavioral data to extract and calibrate against.

The T08 capture contains boot sequence only (1 frame). This task produces a capture with locomotion, jump, and fire inputs active across at least 300 frames.

## Reference Reasoning

`High`

Reasoning basis:

- requires resolving an open Known Gap (Lua frame API returns nil in MAME 0.287)
- input plan must be designed for GNG-specific boot sequence timing (coin insert delay, start screen delay)
- capture must produce evidence files that the frame extractor in T10.2 can actually read
- three independent prerequisites must succeed in sequence before the capture can run

## Scope

- resolve Lua frame signaling API for MAME 0.287
- define `plans/gng_gameplay.yaml` with coin, start, and action inputs for gngb
- execute one capture run of at least 300 frames with active input
- verify private evidence layout contains frames of gameplay (not only boot)

## Out of Scope

- behavioral extraction from captured frames (T10.2)
- timing calibration (T10.3)
- any public output writes (T10.4)
