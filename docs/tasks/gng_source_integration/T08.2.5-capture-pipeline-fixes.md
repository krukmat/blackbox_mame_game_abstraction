## Purpose

Fix three gaps discovered in T08.2.3 that prevented reliable private evidence capture.

## Gaps Resolved

### Gap 1 — `states/` pre-created
`capture_manager.py` now creates `states/` alongside `frames/`, `video/`, `logs/`, `metadata/`.

### Gap 2 — AVI path absolute
`mame_runner.py` resolves `aviwrite_path` to absolute before passing to MAME. AVI now lands in `evidence/private/<run_id>/video/capture.avi` as intended.

### Gap 3 — Lua API updated
`scripts/mame_autoboot.lua` updated to MAME 0.287 API:
- `emu.register_start` → `emu.add_machine_reset_notifier`
- `emu.register_stop` → `emu.add_machine_stop_notifier`
- `emu.framecount()` call removed (returns nil in 0.287; frame counter deferred to T09)

## Known Gap Remaining (T09)

`manager.machine.video.frame_number` returns nil in MAME 0.287 — correct video API path not yet determined. Frame-by-frame Lua signalling is deferred to T09 where it is needed for input sequencing.
