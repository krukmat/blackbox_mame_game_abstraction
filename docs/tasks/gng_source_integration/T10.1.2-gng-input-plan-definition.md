## Purpose

Define a deterministic input plan for `gngb` that exercises all 5 mechanic categories from T09.2: locomotion, jump arc, projectile, gravity/collision, and entity events. The existing `plans/basic_controls.yaml` uses `game_id: sample_game` and covers only locomotion — it cannot be used for GNG calibration.

## Reference Reasoning

`Medium`

Reasoning basis:

- input sequence must account for GNG boot timing: coin insert delay, title screen wait, gameplay start
- plan must produce observable instances of jump, fire, and movement within 300 frames
- wrong timing produces a capture of boot/title screen only (same failure as T08)

## Scope

- create `plans/gng_gameplay.yaml` with `game_id: gngb`
- sequence: `insert_coin` (hold) → `noop` (wait for title) → `press_start` → `noop` (wait for gameplay) → `move_right` → `jump` → `move_right` → `fire` → `noop`
- total frame count: at least 300
- validate the plan file loads without error via `load_input_plan`
- validate against `packages/schemas/input_plan.schema.json` if schema exists

## Out of Scope

- Lua signaling (T10.1.1)
- executing the capture run (T10.1.3)
