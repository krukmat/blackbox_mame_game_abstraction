## Implementation Spec

### `arthur_tracker.py` — `ArthurSignature` dataclass

Add a new field:

```python
@dataclass(slots=True)
class ArthurSignature:
    height_min_px: int = 24
    height_max_px: int = 28
    center_y_min_px: int = 140
    center_y_max_px: int = 195
    aspect_ratio_min: float = 0.40
    aspect_ratio_max: float = 1.10
    max_frame_jump_px: float = 24.0  # T10.7: empirically calibrated upper bound
```

### `arthur_tracker.py` — `find_arthur` filter

After the existing geometric filter and before nearest-neighbor selection, add a distance filter that applies only when `prev_center is not None`:

```python
def find_arthur(self, regions, sig, prev_center=None):
    candidates = [region for region in regions if ...]  # existing geometric filter
    if not candidates:
        return None

    if prev_center is None:
        return candidates[0]

    prev_x, prev_y = prev_center
    # T10.7: drop candidates that teleported beyond the empirical threshold
    max_d_sq = sig.max_frame_jump_px ** 2
    candidates = [
        region for region in candidates
        if (region.center_x - prev_x) ** 2 + (region.center_y - prev_y) ** 2 <= max_d_sq
    ]
    if not candidates:
        return None

    return min(candidates, key=lambda region: (
        (region.center_x - prev_x) ** 2 + (region.center_y - prev_y) ** 2
    ))
```

### Regression test specs

**Test 1 — Beyond-threshold rejection**

```python
def test_find_arthur_rejects_candidate_beyond_max_frame_jump(self) -> None:
    tracker = ArthurTracker()
    sig = ArthurSignature(max_frame_jump_px=24.0)
    # Candidate center=(99.5, 140) passes signature center_y range (140..195)
    # Distance from prev_center=(99.5, 170) is 30.0 px → exceeds 24
    candidate = _region(89, 128, width=22, height=25)  # center=(99.5, 140)

    assert tracker.find_arthur([candidate], sig, prev_center=(99.5, 170.0)) is None
```

**Test 2 — Within-threshold acceptance**

```python
def test_find_arthur_accepts_candidate_within_max_frame_jump(self) -> None:
    tracker = ArthurTracker()
    sig = ArthurSignature(max_frame_jump_px=24.0)
    # Candidate center=(104.5, 178); distance from (99.5, 170) = √(25+64) ≈ 9.43 px
    candidate = _region(94, 166, width=22, height=25)  # center=(104.5, 178)

    assert tracker.find_arthur([candidate], sig, prev_center=(99.5, 170.0)) == candidate
```

**Test 3 — Boundary inclusivity (24.0 px exactly)**

```python
def test_find_arthur_accepts_candidate_at_threshold_boundary(self) -> None:
    tracker = ArthurTracker()
    sig = ArthurSignature(max_frame_jump_px=24.0)
    # Candidate center=(99.5, 194); distance from (99.5, 170) = 24.0 exactly
    candidate = _region(89, 182, width=22, height=25)  # center=(99.5, 194)

    assert tracker.find_arthur([candidate], sig, prev_center=(99.5, 170.0)) == candidate
```

**Test 4 — First-frame bypass (`prev_center=None`)**

```python
def test_find_arthur_max_frame_jump_disabled_when_prev_center_none(self) -> None:
    tracker = ArthurTracker()
    sig = ArthurSignature(max_frame_jump_px=24.0)
    # No prev_center → filter must not apply
    candidate = _region(20, 160, width=22, height=25)  # center=(30.5, 172)

    assert tracker.find_arthur([candidate], sig) == candidate
```
