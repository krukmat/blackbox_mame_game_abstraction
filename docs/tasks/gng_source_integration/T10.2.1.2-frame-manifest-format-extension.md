# T10.2.1.2 - FrameManifest Format Extension

## Status

✅ Done — 2026-05-13

## Files and Lines Affected

| File | Change |
|------|--------|
| `packages/vision/frame_manifest.py` | `from_run` now dispatches PGM vs PNG by glob; added `_read_png` via Pillow; `load_frame_pixels` dispatches by suffix |
| `apps/mame-harness/tests/test_vision_pipeline.py` | 6 new PNG tests added; `_write_png` helper using Pillow |
| `apps/mame-harness/pyproject.toml` | Added `Pillow>=12.0` and `PyYAML>=6.0` to `[project.dependencies]` |

## Purpose

Extend `FrameManifest.from_run` to read the private frame format selected in T10.2.1.1. The current implementation globs `*.pgm` and reads P2 ASCII PGM only, while the real gameplay evidence originates in `video/capture.avi` and must first be materialized into a private frame directory with a defined format and naming pattern.

## Reference Reasoning

`Medium`

Reasoning basis:

- must maintain `ensure_private_evidence_path` on every loaded frame path — the guardrail cannot be relaxed
- if PNG support is needed, must choose reader strategy: stdlib `struct`/`zlib` vs `Pillow` dependency
- existing PGM path must remain intact to avoid breaking current tests

## Objective

Implement the manifest and pixel-reader changes needed for the extracted private frame format chosen in T10.2.1.1, without regressing the existing PGM path or weakening private-path enforcement.

## Scope

- update `FrameManifest.from_run` glob and layout expectations to match the extracted private frame directory from T10.2.1.1
- add `load_frame_pixels` implementation for the chosen extracted format
- keep PGM reader intact for backwards compatibility with existing tests
- TDD: write tests with synthetic fixtures of the chosen format before modifying source

## Out of Scope

- motion diffing or entity extraction (T10.2.2)
- adding any public output (private paths stay private)

## Dependencies

- T10.2.1.1

## Blocks

- T10.2.1.3

## Acceptance Criteria

- `FrameManifest.from_run` returns a non-empty manifest for a directory of extracted private gameplay frames matching the T10.2.1.1 decision
- every `FrameRecord.private_path` passes `ensure_private_evidence_path`
- new format tests added and passing
- existing PGM tests still passing
