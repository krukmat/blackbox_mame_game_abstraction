# T10.8.1 — Enemy Signature Catalog and Calibration

## Status

🔲 Planned — awaiting parent-task approval.

## Parent Task

[T10.8 — Enemy Tracking Continuity](./T10.8-enemy-tracking-continuity.md)

## Objective

Produce calibrated `EnemySignature` bounds for the two enemy types visible in GNG stage 1 screen 1 (zombi and crow) using a human-validated picker workflow (ADR-019). Output a public `specs/calibration/gng_enemy_signatures.yaml` file consumed by `EntityTracker` in T10.8.2 and T10.8.3.

## Scope

- Implement `apps/mame-harness/enemy_signature_picker.py` following ADR-019:
  - Reads `evidence/private/run_t10_4_01/` PNG frames (and any complementary capture).
  - Runs `FrameDiffer` to extract `MotionBox` regions per frame.
  - Excludes regions claimed by `ArthurTracker` (player) to focus on non-player candidates.
  - Clusters remaining regions by (height_band, aspect_ratio_band, center_y_band) over sustained windows (≥ 4 consecutive frames).
  - Surfaces cluster summaries on stdout (frame ranges + numeric bounds — no PNG paths) and writes detailed candidates to `evidence/private/run_<id>/logs/enemy_signature_candidates.json`.
  - Operator validates each cluster against private PNGs and replies y/n; accepted IDs are appended to the candidates file.
- Implement `apps/mame-harness/enemy_signature_calibrator.py`:
  - Reads accepted candidates.
  - Computes per-type bounds with safety margins: `height_min = min(observed) - 2`, `height_max = max(observed) + 2`, `aspect_ratio_min/max ± 0.05`, `center_y_min/max ± 4`.
  - Sets `max_frame_jump_px` from the 95th percentile of observed |Δcenter| between consecutive frames within a cluster, with a 50% safety margin.
  - Sets `gap_tolerance_frames` to 3 (default) unless evidence suggests otherwise.
  - Emits `specs/calibration/gng_enemy_signatures.yaml`.
- If `run_t10_4_01` yields fewer than 5 accepted clusters for either type, perform a short complementary capture (`run_t10_8_enemies`) targeting that gap.

## Out of Scope

- Red Arremer, cyclops, or any boss signature calibration.
- Static hazard (plants/cactus) classification — unchanged.
- Modifying `gng_vision_config.py` semantics for HUD masking or MOG2 parameters.
- Modifying `ArthurSignature` defaults — they stay calibrated for the player.

## Dependencies

- ✅ T10.7.B — duplicate player collision fix is required to ensure cluster candidates are not contaminated by misclassified player blobs.
- ✅ T10.5/T10.6 — `FrameDiffer` and `ArthurTracker` infrastructure for region extraction and player exclusion.

## Reasoning Grade

`Medium`

Reasoning basis:
- Boundary-sensitive evidence interpretation requires careful clean-room separation: picker reads private PNGs but emits only numeric data.
- Cluster heuristics need empirical tuning to surface coherent candidates without overwhelming the operator.

## Effort Grade

`M`

## Recommended Model

`Sonnet`

## Acceptance Criteria

1. `apps/mame-harness/enemy_signature_picker.py` exists with a CLI entry point taking a `--run-id` argument.
2. Picker writes `evidence/private/run_<id>/logs/enemy_signature_candidates.json`; stdout contains no PNG paths.
3. `apps/mame-harness/enemy_signature_calibrator.py` reads accepted candidates and writes `specs/calibration/gng_enemy_signatures.yaml` with sections for `zombi` (entity_type=enemy_a) and `crow` (entity_type=enemy_b).
4. The YAML passes `ensure_no_private_paths`.
5. Operator has accepted ≥ 5 clusters for each of zombi and crow.
6. Bounds are documented with `sample_count`, `calibration_source` (which run_id), and `calibration_method: enemy_signature_picker` per ADR-019.
7. Regression test confirms `enemy_signature_picker` excludes player-claimed regions from candidate output.
8. Regression test confirms `enemy_signature_calibrator` rejects clusters with `sample_count < 4` (single-frame flicker filter).
