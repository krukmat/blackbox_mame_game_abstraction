# T10.9.1 — Scroll Detection + MOG2 Reset (ADR-022)

## Status

🔲 Planned — awaiting parent-task approval.

## Parent Task

[T10.9 — Boss and Devil Tracking](./T10.9-boss-and-devil-tracking.md)

## Objective

Implement `ScrollDetector` (ADR-022) and wire MOG2 background-model reset at the end of each detected scroll event. This resolves the ADR-013 "MOG2 scroll reset" Known Gap and is the precondition for any post-scroll entity detection (boss tracking in T10.9, future stage 2+ work).

## Scope

- Create `packages/vision/scroll_detector.py`:
  - `ScrollEvent` dataclass with `frame_start`, `frame_end`, `total_shift_px`, `direction`.
  - `ScrollDetector` class with `step(prev_frame, curr_frame, player_mask, frame_index) -> ScrollEvent | None`.
  - Detection algorithm: integer pixel-shift cross-correlation in `[-max_shift_px, +max_shift_px]`, optional player-mask exclusion, debounce by `scroll_streak_frames` and `post_scroll_debounce_frames`.
- Modify `packages/vision/frame_differ.py` (or the pipeline orchestrator) to:
  - Run `ScrollDetector.step` before MOG2 update each frame.
  - On `ScrollEvent` emission (end-of-scroll), rebuild the MOG2 background subtractor.
  - Suppress non-player `EntityTracker` output for `mog2_warmup_frames` frames following the reset.
  - `ArthurTracker` continues to operate during warmup (signature-based, not background-based).
- Wire `gng_vision_config.reset_on_scroll` so that setting it `False` reverts to pre-T10.9 behavior.
- Add unit tests in `packages/vision/tests/test_scroll_detector.py`.
- Add integration test in `packages/vision/tests/test_pipeline_scroll_integration.py` covering reset-and-warmup behavior end-to-end against synthetic frame sequences.

## Out of Scope

- Vertical scroll (not present in GNG).
- ROM-state introspection (forbidden by clean-room policy).
- Signature calibration for Red Arremer or cyclops (T10.9.2 and T10.9.3).
- Trace regeneration (T10.9.5).

## Dependencies

- ✅ T10.8.2 — `EntityTracker` exists and is the consumer of the warmup-suppression logic.

## Reasoning Grade

`High`

Reasoning basis:
- New module with a non-trivial algorithm (cross-correlation, debounce, masking).
- Pipeline ordering invariant must be enforced.
- MOG2 lifecycle change affects every frame in scrolling runs.

## Effort Grade

`M`

## Recommended Model

`Sonnet`

## Acceptance Criteria

1. `packages/vision/scroll_detector.py` exists with the declared API.
2. Unit tests cover:
   - Pure-horizontal-shift sequence → `ScrollEvent` emitted with correct `total_shift_px` and `direction`.
   - Static-camera sequence → no events emitted.
   - Brief shift below `scroll_streak_frames` → no event (debounce works).
   - Player-mask exclusion: a sequence where the only motion is inside the masked region produces no scroll event.
3. Integration test in `test_pipeline_scroll_integration.py` confirms MOG2 reset at `ScrollEvent` end and entity-tracker suppression during warmup.
4. `gng_vision_config.reset_on_scroll = False` reverts behavior to pre-T10.9 (no scroll detection invoked).
5. `ArthurTracker` output is unchanged across the warmup window in the integration test (player tracking continues).
6. No path strings or private-evidence references introduced.
7. `pytest packages/vision/tests/` passes in full.
