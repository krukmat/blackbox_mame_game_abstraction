# T11.2 - Trace Episode Extractor

## Status

✅ Done

## Objective

Define an episode artifact and implement a Python extractor that converts `specs/traces/gng_trace.json` into a compact public file at `specs/episodes/gng_episodes.json` so the RN prototype can load scenario-sized trace segments instead of ingesting the full trace.

## Scope

- Design the episode schema for public runtime consumption:
  - `id`
  - `frame_start`
  - `frame_end`
  - `frames`
  - per-frame `player`, `enemies`, and `projectiles` payloads
- Implement `apps/mame-harness/episode_extractor.py`
- Read from `specs/traces/gng_trace.json`
- Group consecutive player-present frames into bounded episodes
- Extract at least 3 episodes, each containing at least 1 jump event
- Write `specs/episodes/gng_episodes.json`
- Enforce clean-room guardrails on the output
- Add focused tests for extractor behavior and output safety

## Out of Scope

- Loading episodes in RN
- Physics calibration
- Modifying `trace.schema.json`
- Scene construction in the RN prototype

## Dependencies

- `T10.4` complete: requires the quality-gated public trace with sufficient jump coverage
- `T11.1` complete: loader and timing wiring are already in place and inform the shape expected by downstream RN consumers

## Reasoning Grade

`High`

Reasoning basis:
- Episode boundary logic must handle sparse player detection and gap-tolerance side effects coherently.
- This introduces a new public artifact surface under `specs/episodes/`.
- The task crosses the public-output boundary and must preserve ADR-003 / ADR-006 constraints.

## Effort Grade

`M`

## Recommended Model

`Sonnet`

## Acceptance Criteria

- `apps/mame-harness/episode_extractor.py` runs without error on the T10.4 trace
- `specs/episodes/gng_episodes.json` is produced successfully
- Output contains at least 3 episodes
- Each episode contains at least 1 `jump_start` event
- Episode coordinates are normalized (`0.0` to `1.0`), with no pixel addresses or frame file references
- `ensure_no_private_paths` passes on the output payload
- Output file size is `<= 500 KB`
- Python tests pass

### ST1 — Schema + TDD setup
- Define `EpisodeFrame` dataclass: `frame`, `player`, `enemies`, `projectiles`
- Define `Episode` dataclass: `id`, `frame_start`, `frame_end`, `frames`
- Define `EpisodesArtifact` dataclass: `episodes`
- Write failing tests for schema structure and serialization
- **Files affected:** `apps/mame-harness/episode_extractor.py`, `apps/mame-harness/tests/test_episode_extractor.py`

### ST2 — Boundary detection
- Iterate player frames sorted by frame number
- Detect gaps > `GAP_THRESHOLD` (default 30 frames) → episode boundary
- Group consecutive player-present frames into runs
- Filter: only keep runs with ≥ 1 `jump_start` event
- Select ≥ 3 qualifying episodes
- **Key invariant:** gap-tolerance from ADR-013 means player may be absent for short windows without ending an episode
- **Files affected:** `apps/mame-harness/episode_extractor.py`

### ST3 — Per-frame entity grouping
- For each frame index in an episode's range, collect all trace entries for that frame
- Partition by entity type: `player` → single dict, `enemy_a` → list, `projectile` → list
- Fields to include per entity: `x`, `y`, `velocity_x`, `velocity_y`, `state`, `events`
- Exclude `entity_id` raw strings that could contain frame references; include `entity_type`
- All coordinates already normalized (0.0–1.0) — no conversion needed
- **Files affected:** `apps/mame-harness/episode_extractor.py`

### ST4 — Guardrails
- Add `validate_artifact(artifact, output_path)` function in `episode_extractor.py`
- Call `ensure_public_output_path(output_path)` — rejects blocked suffixes (`.png`, `.avi`, etc.)
- Call `ensure_no_private_paths(dataclasses.asdict(artifact))` — recursively checks all nested strings
- Add 3 tests:
  - `test_validate_artifact_passes_on_real_output` — passes on real artifact + valid output path
  - `test_validate_artifact_rejects_blocked_suffix` — raises `ValueError` for `.png` output path
  - `test_validate_artifact_rejects_private_path_in_payload` — raises `ValueError` if `evidence/private/` appears in any event string
- **Files affected:** `apps/mame-harness/episode_extractor.py`, `apps/mame-harness/tests/test_episode_extractor.py`

### ST5 — File write + validation
- Implement `write_episodes(artifact, output_path)` in `episode_extractor.py`:
  - Call `validate_artifact(artifact, output_path)` before writing (ADR-003/ADR-006 gate)
  - Create `specs/episodes/` directory if absent
  - Write JSON with `json.dump(indent=2)`
- Add 3 tests:
  - `test_write_episodes_creates_file` — file exists after call
  - `test_written_file_size_under_500kb` — file size ≤ 500 KB
  - `test_written_file_contains_valid_episodes` — JSON parses, ≥ 3 episodes, each with ≥ 1 `jump_start`
- **Files affected:** `apps/mame-harness/episode_extractor.py`, `specs/episodes/gng_episodes.json`, `apps/mame-harness/tests/test_episode_extractor.py`
