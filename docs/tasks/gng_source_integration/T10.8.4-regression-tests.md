# T10.8.4 — Regression Test Suite for Enemy Tracking

## Status

🔲 Planned — awaiting parent-task approval.

## Parent Task

[T10.8 — Enemy Tracking Continuity](./T10.8-enemy-tracking-continuity.md)

## Objective

Consolidate and extend the regression test coverage introduced by T10.8.2 and T10.8.3 to lock in the documented invariants of `EntityTracker` and the per-entity lifecycle in `extract_trace`. Tests are added alongside the implementation (project policy: not TDD-first; see `CLAUDE.md` "Coding Standards").

## Scope

- Add `packages/vision/tests/test_enemy_tracking_integration.py` covering scenarios that span tracker + extractor + ArthurTracker:
  - **Scenario A — Lone zombi walk**: synthetic 20-frame sequence with one zombi walking right; expect one persistent `entity_id`, one `spawn`, no `die`, monotonic position progression.
  - **Scenario B — Two concurrent zombis**: synthetic 20-frame sequence with two zombis at separated y-positions; expect two distinct `entity_id` values, no swap, two `spawn` events, no `die`.
  - **Scenario C — Two zombis spawned at different times**: zombi A from frame 0, zombi B from frame 10; expect two `entity_id` values with different `spawn_frame` components.
  - **Scenario D — Zombi occluded by player**: zombi and player overlap for 2 frames within `gap_tolerance`; expect zombi `entity_id` persists; no spurious `die` event.
  - **Scenario E — Zombi dies (off screen)**: zombi disappears for `gap_tolerance + 1` frames; expect `die` event on its last-seen entry.
  - **Scenario F — Crow vertical oscillation**: synthetic 30-frame sequence with a crow oscillating in y; expect one persistent `entity_id` regardless of `velocity_y` sign changes.
  - **Scenario G — Player and zombi do not collide on ID**: player at signature-overlapping height for one frame; expect player keeps `entity_id="player"` and zombi keeps its own.
  - **Scenario H — Greedy ID stability under cross-path** (acceptance scenario, not negative): two zombis approaching but not crossing within `max_frame_jump_px`; expect no swap. (Cross-path inside the ceiling is an accepted limitation; do not test as success.)
  - **Scenario I — Legacy aggregate path unchanged**: harness-style aggregate single-blob input produces the same output as before T10.8 (parity test against snapshot).
- Add fixture helpers in `packages/vision/tests/conftest.py` (or new `_fixtures.py`) for constructing synthetic `FrameDiffStat` sequences with controlled `MotionBox` positions.
- Ensure the existing test count grows; no existing test is deleted to make a new one pass. Per CLAUDE.md: **no commit if tests are broken**.

## Out of Scope

- Tests against real PNG frames (those run via the regeneration gate in T10.8.5).
- Performance benchmarks.
- Tests for boss tracking — deferred to T10.9.
- Tests for projectile in-flight tracking — covered by T10.7.E.
