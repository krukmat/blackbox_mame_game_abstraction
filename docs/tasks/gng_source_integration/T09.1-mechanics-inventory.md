### Category 1 — Locomotion

Observable: x-position changes at constant velocity while left/right input is held. Velocity is zero when input is released. No acceleration or inertia.

| Observable | Type | Notes |
|-----------|------|-------|
| `velocity_x` | number | constant while input held, 0 on release |
| `state` | string | `idle`, `walking_left`, `walking_right` |

Excluded: character name, sprite appearance, color.

### Category 2 — Jump arc

Observable: deterministic trajectory — fixed initial Y velocity, constant gravity, fixed duration. Jump cannot be cancelled mid-air.

| Observable | Type | Notes |
|-----------|------|-------|
| `velocity_y` | number | negative ascending, positive descending |
| `state` | string | `grounded`, `ascending`, `descending` |
| `events` | list | `jump_start`, `jump_peak`, `land` |

Excluded: jump sprite frame, pixel height of art.

### Category 3 — Projectile timing

Observable: fixed delay between fire input and projectile spawn. Constant horizontal velocity. Maximum one projectile on screen at a time.

| Observable | Type | Notes |
|-----------|------|-------|
| `velocity_x` | number | constant, same direction as player |
| `events` | list | `fire`, `hit_enemy`, `hit_wall`, `despawn` |
| `spawn_delay_frames` | integer | input → spawn delay in frames |

Excluded: projectile shape, name (lance/torch).

### Category 4 — Gravity and collision state

Observable: constant Y acceleration while airborne. Collision with ground sets state to `grounded` and `velocity_y = 0`.

| Observable | Type | Notes |
|-----------|------|-------|
| `velocity_y` delta per frame | number | constant in air |
| `state` | string | `grounded`, `airborne` |
| `events` | list | `land`, `fall` |

### Category 5 — Entity event trace

Observable: per-frame event sequence for each active entity. Base contract already defined in `trace.schema.json`.

| Observable | Type | Notes |
|-----------|------|-------|
| `spawn` | event | entity appears |
| `hit` | event | entity takes damage |
| `die` | event | entity removed |
| `score` | event + `score_delta` int | points awarded |

### Clean-room exclusion list

- frame/crop paths
- character names with copyright (use `player`, `enemy_a`, etc.)
- visual sprite descriptions
- hardcoded RAM or ROM values
- absolute pixel coordinates (use abstract units)

## Note on Timing Values

All timing values (gravity constant, jump velocity, projectile speed) must be calibrated in T10 from a real gameplay capture with an active input plan. The T08 capture contains boot sequence only — no gameplay data yet.
