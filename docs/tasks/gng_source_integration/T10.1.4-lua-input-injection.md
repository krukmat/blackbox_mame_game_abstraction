## Purpose

Implement frame-accurate input injection in `scripts/mame_autoboot.lua` so that MAME executes the inputs defined in `plans/gng_gameplay.yaml` at the correct frames. Without this, all captures are attract-mode only — no real gameplay is observable.

The Lua frame callback (T10.1.1.2) already fires on every frame and emits the frame number. This task extends it to also inject the correct button state for that frame by reading a pre-exported JSON frame plan.

## Reference Reasoning

`High`

Reasoning basis:

- requires understanding MAME 0.287 ioport Lua API for button injection
- must bridge Python (input_planner) → JSON → Lua with correct field mapping
- MAME ioport field names for gngb must be discovered (not assumed)
- button injection must be reversible per frame (pressed then released)
- incorrect injection produces silent wrong gameplay, not an error

## Scope

### Python side
- Add `InputPlan.export_to_json(path: Path)` that writes a flat array:
  `[{"frame": 0, "buttons": []}, {"frame": 1, "buttons": ["right"]}, ...]`
- `cli.py` exports the JSON to a temp path before invoking MAME
- The JSON path is passed to the Lua script via a known env var or a fixed temp path (e.g. `/tmp/gng_input_plan.json`)

### Lua side
- On script init, read and parse the JSON frame plan from the known path
- In the `emu.add_machine_frame_notifier` callback, look up `buttons` for the current frame
- For each button in the list, find the corresponding ioport field and set it active
- Clear all injected fields at the start of each frame (prevent stuck buttons)

### MAME ioport field discovery
- Enumerate `manager.machine.ioport.ports` for gngb to find the correct field tags for: coin, start, left, right, up, down, button1 (jump), button2 (fire)
- Document the discovered field tags under `## IOPORT Field Map` in this file

## Out of Scope

- input recording via `-record` flag (not needed for injection)
- multi-player inputs
- any change to the YAML plan format

## IOPORT Field Map

Discovered against MAME `0.287` with live Lua probing on driver `gngb`:

| Plan button | Port tag | Field name |
|---|---|---|
| `coin` | `:SYSTEM` | `Coin 1` |
| `start` | `:SYSTEM` | `1 Player Start` |
| `left` | `:P1` | `P1 Left` |
| `right` | `:P1` | `P1 Right` |
| `up` | `:P1` | `P1 Up` |
| `down` | `:P1` | `P1 Down` |
| `button1` | `:P1` | `P1 Button 1` |
| `button2` | `:P1` | `P1 Button 2` |
