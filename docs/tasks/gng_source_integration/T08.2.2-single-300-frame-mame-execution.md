## Fix Applied During This Task

`mame_runner.py:79` — `-frames_to_run` flag removed by MAME 0.287. Replaced with conversion to `-seconds_to_run` via `MAME_FRAME_RATE = 60` constant. 2 new tests added: `test_frames_to_run_emits_seconds_to_run`, `test_frames_to_run_ceiling_conversion`.

## Known Gap (Risk for T09)

`scripts/mame_autoboot.lua:6` — `emu.framecount()` is a nil value in MAME 0.287. The Lua API was changed. MAME ran and exited cleanly (returncode 0) because `-seconds_to_run 5` controlled the duration, not the Lua script. However, the autoboot script's frame-counting logic will not work for T09 input sequencing. Also: `emu.register_start` and `emu.register_stop` are deprecated — replacements are `emu.add_machine_reset_notifier` and `emu.add_machine_stop_notifier`.
