### Known Gap — frames/ tiene solo 1 PNG

`-snapshot_directory` en MAME no escribe un PNG por frame automáticamente. Solo produce el snapshot de arranque (`0000.png`). El AVI (`-aviwrite`) es la fuente de evidencia multi-frame y tiene los 359 frames.

El criterio original "frames/ contiene >1 archivo" asumía que MAME escribía PNGs individuales — este supuesto es incorrecto. **El AVI es la evidencia correcta para T10.2.**

Para T10.2.1.1 (frame format analysis), el pipeline debe leer de `video/capture.avi` y extraer frames con `ffmpeg -i capture.avi frames/%04d.png`, no asumir PNGs pre-existentes en `frames/`.
