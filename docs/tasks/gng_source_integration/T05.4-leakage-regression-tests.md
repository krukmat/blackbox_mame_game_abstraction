# T05.4 - Leakage Regression Tests

## Status

Completed — 2026-05-13

Test file: `apps/mame-harness/tests/test_redaction_regression.py` — 33 tests, all passing.

## Purpose

Verify through end-to-end regression tests that no sensitive path class escapes into public metadata across the full `handle_run` pipeline — combining sanitization (T05.3) and guardrail enforcement (T05.3.4) together rather than testing each layer in isolation.

## Parent Task

- `T05 - Public Metadata Redaction Hardening`

## Parent Cataloging

- Reasoning grade: `Medium`
- Effort grade: `Medium`
- Recommended model: `claude-sonnet-4-6`

## Cataloging Rationale

`T05.4` is `Medium` reasoning because the policy is already fixed by T05.2 and implemented by T05.3. The task's risk is coverage design: identifying which combined input scenarios expose gaps that unit tests miss. Effort is `Medium` because the full metadata pipeline must be exercised via controlled mocks rather than individual function calls.

## Scope

- regression tests that construct a realistic `MameRunResult` with path-bearing values and verify the final metadata written by `handle_run` is clean
- coverage of each sensitive class (S1–S8 from T05.2.4) across all affected public fields
- verification that `write_public_metadata` rejects any payload that passes through with unsanitized paths (defense-in-depth check)
- tests live in `apps/mame-harness/tests/test_redaction_regression.py`

## Out of Scope

- live MAME execution
- frame capture or vision pipeline output
- testing T05.3 sanitization functions in isolation (those are covered in `test_cli.py` and `test_metadata_writer.py`)

## Dependencies

- `T05.3` — implementation complete
- `T05.2.4` — decision table (defines what to assert against)
- `T05.2.2` — allowed forms (defines what must survive sanitization)

## Blocks

- `T05.5` — contract documentation must reference verified behavior
- `T06` — GNG contract tests include redaction coverage as a prerequisite

## Acceptance Criteria

- one regression test per sensitive class (S1–S8) exercising the full `handle_run` metadata path
- each test asserts that the final metadata dict contains no blocked path form
- each test asserts that allowed replacement forms (`private://`, `<redacted:path>`, path-free text) are present where expected
- `write_public_metadata` is called with the final metadata and must not raise
- all tests are deterministic and CI-safe (no real MAME binary, no filesystem side effects beyond `tmp_path`)

## Subtasks

### T05.4.1 — Regression fixture setup

- Objective: create a shared `build_run_result` fixture that constructs a `MameRunResult` with configurable path-bearing fields.
- Scope:
  - `command` with private evidence paths, ROM paths, absolute paths
  - `preflight.issues` with path-bearing messages
  - `execution.stdout` and `execution.stderr` with MAME-like path-bearing output
- Out of scope: real subprocess calls
- Dependencies: `T05.3`
- Reasoning grade: `Low`
- Effort grade: `Low`
- Recommended model: `claude-haiku-4-5`
- Acceptance criteria: fixture is reusable across all T05.4.x tests

### T05.4.2 — S1/S2 regression: private evidence and frame paths

- Objective: assert that `evidence/private/...` and `.../frames/...` paths are absent from final metadata.
- Scope: `command[*]`, `execution.stdout`, `execution.stderr`
- Dependencies: `T05.4.1`
- Reasoning grade: `Low`
- Effort grade: `Low`
- Recommended model: `claude-haiku-4-5`
- Acceptance criteria: no `evidence/private` or `/frames/` string survives into written metadata

### T05.4.3 — S4/S5 regression: ROM paths and absolute machine paths

- Objective: assert that ROM zip paths and absolute local paths are absent from all public metadata fields.
- Scope: `command[*]`, `preflight.issues[*].message`, `execution.stdout`, `execution.stderr`
- Dependencies: `T05.4.1`
- Reasoning grade: `Low`
- Effort grade: `Low`
- Recommended model: `claude-haiku-4-5`
- Acceptance criteria: no `/Users/...`, `/home/...`, `C:\...` or `*.zip` path survives

### T05.4.4 — S6 regression: non-approved workspace paths are blocked; repo-safe paths survive

- Objective: assert that only allowlisted repo-safe relative references (e.g., `scripts/mame_autoboot.lua`) survive in `command[*]`; all others are redacted.
- Scope: `command[*]`
- Dependencies: `T05.4.1`
- Reasoning grade: `Low`
- Effort grade: `Low`
- Recommended model: `claude-haiku-4-5`
- Acceptance criteria: `scripts/mame_autoboot.lua` present; arbitrary relative paths absent

### T05.4.5 — Defense-in-depth: guardrail rejects unsanitized payload

- Objective: assert that if a caller bypasses sanitization and passes a path-bearing payload directly to `write_public_metadata`, the call raises `ValueError`.
- Scope: `write_public_metadata`, `ensure_no_private_paths`
- Dependencies: `T05.4.1`
- Reasoning grade: `Low`
- Effort grade: `Low`
- Recommended model: `claude-haiku-4-5`
- Acceptance criteria: `write_public_metadata` raises on any S1–S5 path in any nested field
