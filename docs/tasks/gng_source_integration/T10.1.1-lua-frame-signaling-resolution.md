## Purpose

Resolve the Known Gap from T08.2.5: `manager.machine.video.frame_number` returns nil in MAME 0.287. The harness needs reliable per-frame signals from the Lua script to coordinate input injection and frame-accurate evidence collection.

## Reference Reasoning

`High`

Reasoning basis:

- the correct MAME 0.287 Lua API for frame counting is not documented in the current codebase
- a wrong API path produces silent nil returns — the script appears to work but emits no frame signals
- the output of this task (a verified Lua signaling mechanism) is a prerequisite for T10.1.2 and T10.1.3

## Scope

- verify signals appear in MAME output with a short dry run

## Out of Scope
