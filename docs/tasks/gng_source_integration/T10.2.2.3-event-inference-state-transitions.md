## Purpose

Implement event list inference from consecutive state pairs and the active input plan action. This is the highest naming-drift risk in the entire extraction pipeline (ADR-008 Known Gap): event strings must match the T09.2 canonical vocabulary exactly — a single character difference (`"jump_start"` vs `"jumpstart"`) causes a silent false mismatch in `BehavioralDiff.compare`.

## Reference Reasoning

`Medium`

Reasoning basis:

- event inference table is defined in the T10.2.2.1 contract — implementation follows it directly
- input plan correlation adds complexity: `fire` and `jump_start` may need to be injected from the plan when visual motion is ambiguous or absent on that frame
- mutual exclusivity constraints (e.g. `land` and `fall` cannot co-occur) must be enforced

## Scope

- TDD: add event inference tests to `test_trace_extractor.py` covering all transition pairs before writing source
- implement `_infer_events(prev_state: str, curr_state: str, input_action: str) -> list[str]`
- transition table from T10.2.2.1 contract: `grounded→airborne` = `[jump_start]`, `ascending→descending` = `[jump_peak]`, `airborne→grounded` = `[land]`, `grounded→airborne` via fall = `[fall]`, `input_action == fire` = `[fire]`, entity appearance = `[spawn]`, entity disappearance = `[die, despawn]`
- enforce: `land` and `fall` mutually exclusive; `fire` only when input action is `fire`; `[] ` on interior frames with no transition
