## Purpose

Implement per-frame signal emission in `scripts/mame_autoboot.lua` using the API path confirmed in T10.1.1.1. Each frame must emit a signal readable by the harness so that input injection and evidence collection can be frame-accurate.

## Reference Reasoning

`Medium`

Reasoning basis:

- implementation follows directly from the API contract confirmed in T10.1.1.1
- risk is in edge cases: first frame, reset events, frame counter wrap-around
- existing notifiers (reset, stop) must not be broken

## Scope

- register a per-frame callback using the MAME 0.287 API confirmed in T10.1.1.1
- emit `blackbox_harness:frame:<N>` on each frame via the chosen signal channel
- preserve existing `blackbox_harness:start` and `blackbox_harness:stop` notifiers
- keep the script idempotent across machine resets

## Out of Scope

- verifying signals in a real MAME run (T10.1.1.3)
- input injection logic

## Dependencies

- T10.1.1.1

## Blocks

- T10.1.1.3

## Acceptance Criteria

- `scripts/mame_autoboot.lua` contains a per-frame callback using the confirmed API
- the callback emits `blackbox_harness:frame:<N>` where N is a monotonically increasing integer
- existing reset/stop notifiers remain present and unmodified
- script has no syntax errors (verifiable with `luac` or equivalent)
