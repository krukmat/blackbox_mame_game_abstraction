### ST1 — Implement `max_frame_jump_px` + regression tests

The threshold `max_frame_jump_px = 24.0` is empirically derived from the |Δy| distribution of consecutive player frames in the current `gng_trace.json` (bimodal histogram with a clear valley between the real-motion cluster and the bug-teleport cluster). See `docs/plans/T10.7-tracker-continuity-fix.md` "Empirical Calibration" section for the supporting data.

**Implementation:**
- Add `max_frame_jump_px: float = 24.0` field to `ArthurSignature` dataclass
- In `find_arthur`, before the nearest-neighbor selection, filter `candidates` by `(region.center_x - prev_x)² + (region.center_y - prev_y)² <= max_frame_jump_px²`
- Apply filter only when `prev_center is not None` (first-frame case must not block detection)

**Regression tests** (added to `packages/vision/tests/test_arthur_tracker.py` after implementation):
- `test_find_arthur_rejects_candidate_beyond_max_frame_jump` — candidate at center=(99.5, 140), prev=(99.5, 170), distance≈30 px → returns `None`
- `test_find_arthur_accepts_candidate_within_max_frame_jump` — candidate at center=(104.5, 178), distance≈9.43 px → returns candidate
- `test_find_arthur_accepts_candidate_at_threshold_boundary` — candidate at center=(99.5, 194), distance=24.0 exact → returns candidate (inclusive boundary)
- `test_find_arthur_max_frame_jump_disabled_when_prev_center_none` — first frame case bypasses filter
- Run `pytest packages/vision/tests/test_arthur_tracker.py -v` — all pass (existing 9 + new 4)

**Files affected:** `packages/vision/arthur_tracker.py`, `packages/vision/tests/test_arthur_tracker.py`

### ST2 — Implement `MIN_GROUND_STREAK` debounce + regression tests

**Implementation:**
- Add module-level constant `MIN_GROUND_STREAK: int = 3` in `trace_extractor.py`
- Extend `_infer_events` signature to accept `ground_streak: int = 0` (default preserves existing callers)
- Inside `_infer_events`: when computing the `_PRE_JUMP_STATES → ascending` transition, suppress `jump_start` if `ground_streak < MIN_GROUND_STREAK`
- In `extract_trace`, maintain a per-entity `ground_streak_by_entity: dict[str, int]`:
  - Increment when curr_state ∈ `_GROUNDED_STATES`
  - Reset to 0 when curr_state == "ascending"
  - Pass to `_infer_events`
- Skip debounce when `legacy_aggregate_compat=True` to preserve harness-test contract

**Regression tests** (added to `packages/vision/tests/test_trace_extractor_multi.py` or new file `test_trace_extractor.py`):
- `test_jump_start_not_emitted_when_ground_streak_below_min` — synthetic sequence ascending → idle (1 frame) → ascending should NOT fire a second jump_start
- `test_jump_start_emitted_when_ground_streak_meets_min` — sequence ascending → idle (3 frames) → ascending SHOULD fire jump_start
- `test_ground_streak_resets_on_ascending` — counter resets correctly
- `test_legacy_aggregate_path_unchanged` — `legacy_aggregate_compat=True` path retains existing behavior

**Files affected:** `packages/vision/trace_extractor.py`, `packages/vision/tests/test_trace_extractor*.py`

## Risks

- **R1 — `max_frame_jump_px=24` may reject extreme falls**: Mitigated empirically — observed max real motion is 14 px/frame with 70% safety margin. If an off-screen death exceeds 24 px, `player_gap_tolerance` handles it gracefully.
- **R2 — `MIN_GROUND_STREAK=3` may reject rapid re-jumps**: Validate against input-plan frames with back-to-back jumps <3 frames apart; relax to 2 if false-rejects observed
- **R3 — Episode regeneration may drop below 3 episodes**: If cleaner trace yields fewer qualifying episodes, may need to adjust `episode_extractor.GAP_THRESHOLD` to be more permissive
