# T10.7 ST6 — Documentation Sync After Calibration Remediation

## Status

✅ Complete — ADR, vault notes, operator docs, and parent task state updated.

## Parent Task

[T10.7 — Tracker Continuity Fix](./T10.7-tracker-continuity-fix.md)

## Objective

Bring the architecture and operator-facing documentation into agreement with
the completed T10.7 remediation path, so the documented Known Gaps, calibration
history, and handoff guidance no longer describe the superseded T11.3 noisy
physics values as current state.

## Scope

- Update `docs/adr/ADR-013-opencv-vision-backend.md`:
  - note that the tracker instability behind the noisy T11.3 calibration was
    addressed by T10.7 follow-up work
  - add `max_frame_jump_px` to the documented config/behavior summary where
    relevant
- Update `docs/obsidian/Vision Layer.md` with a concise T10.7 remediation
  summary that references the relevant ADRs and T10.7 subtasks
- Update the Known Gaps sections in `AGENTS.md` and `CLAUDE.md` so they reflect
  the post-T10.7 state instead of the superseded pre-fix calibration narrative
- Append a resolution note to `docs/handoff_t11_3_physics_calibration.md`
  pointing future contributors to the T10.7 calibrated values and follow-up
  tasks
- Mark ST6 complete in the parent T10.7 task file after the documentation is
  updated

## Out of Scope

- Any code changes in `packages/vision/`, `apps/mame-harness/`, or
  `apps/rn-prototype/`
- New calibration runs, trace regeneration, or episode regeneration
- Full test-suite execution (that remains ST7)
- New ADR creation or architectural scope changes
