# T11.3 - Physics Calibration from Trace

## Status

✅ Complete

## Objective

Measure the four physics constants used by the RN `PhysicsSystem` directly from player trace events in `specs/traces/gng_trace.json`, produce a public calibration artifact, and wire the measured values into both `gng_abstract_mechanics.yaml` and `PhysicsSystem.ts`.

## Scope

- Implement `apps/mame-harness/physics_calibrator.py`:
  - Read player entries from `specs/traces/gng_trace.json`
  - Measure `locomotion_velocity_x`: mean of `|velocity_x|` across moving player frames (state != idle)
  - Measure `jump_velocity_y`: mean of `|velocity_y|` at `jump_start` events
  - Measure `gravity_units_per_frame`: mean of `Δvelocity_y` between consecutive ascending/descending player frames
  - Measure `projectile_velocity_x`: mean of `|velocity_x|` across projectile entries
  - Report each constant with `value`, `sample_count`, and `std_dev`
  - Enforce sample_count ≥ 10 for each constant; raise `ValueError` otherwise
  - Output: `specs/calibration/gng_physics_calibration.yaml`
- Unit conversion: trace values are normalized (0.0–1.0 per frame); PhysicsSystem uses units/second
  - Conversion: `value_per_second = value_per_frame / (ms_per_frame / 1000)`
  - `ms_per_frame = 16.768` (from `gng_abstract_mechanics.yaml`)
- Update `specs/mechanics/gng_abstract_mechanics.yaml`:
  - Replace `calibration: pending` with measured values for:
    - `locomotion.fields.velocity_x`
    - `jump_arc.fields.velocity_y`
    - `gravity_collision.fields.gravity_units_per_frame`
    - `projectile.fields.velocity_x`
  - Add `calibrated_value` and `sample_count` fields alongside each updated field
- Update `apps/rn-prototype/src/engine/PhysicsSystem.ts`:
  - Replace hardcoded defaults (`gravity: 9.8, moveSpeed: 3, jumpVelocity: 6`) with calibrated values
  - Values sourced from `gng_physics_calibration.yaml` — document the source in a comment
- Add Python tests for calibrator behavior and output safety
- Add TypeScript test asserting PhysicsSystem uses calibrated values (not hardcoded stubs)

## Out of Scope

- Enemy or projectile mass calibration
- Collision size or hitbox calibration
- Spawn delay measurement (projectile.spawn_delay_frames)
- Modifying the trace schema

## Dependencies

- T11.2 complete: `specs/traces/gng_trace.json` with ≥ 87 complete jump arcs (verified)
- T11.1 complete: `mechanicsLoader.ts` and TypeScript mechanics types exist

## Reasoning Grade

`High`

Reasoning basis:
- Trace velocity values are normalized ratios (0.0–1.0) — unit conversion to PhysicsSystem units/second requires explicit ms_per_frame division
- Jump arc peak detection is noisy: player may be absent at the exact peak frame due to gap-tolerance; algorithm must be robust to missing frames
- PhysicsSystem uses a coordinate system where y increases upward; trace uses screen coordinates (y increases downward) — sign inversion required for velocity_y
- Measured values must be physically plausible for a platform game (sanity bounds required)

## Effort Grade

`M`

## Recommended Model

`Sonnet`

## Acceptance Criteria

- `physics_calibrator.py` runs without error on `specs/traces/gng_trace.json`
- `specs/calibration/gng_physics_calibration.yaml` is produced with 4 constants
- Each constant has `sample_count ≥ 10`
- `gng_abstract_mechanics.yaml` has no remaining `calibration: pending` fields for locomotion, jump_arc, gravity_collision, and projectile
- `PhysicsSystem.ts` default config reflects calibrated values (not `gravity: 9.8, moveSpeed: 3, jumpVelocity: 6`)
- All Python tests pass
- All TypeScript tests pass (existing + new)

### ST1 — physics_calibrator.py

- Load trace, separate player and projectile entries
- `locomotion_velocity_x`: `mean(|velocity_x|)` for player frames where `state != idle`
- `jump_velocity_y`: `mean(|velocity_y|)` at frames with `jump_start` in events
- `gravity_units_per_frame`: `mean(Δvelocity_y)` between consecutive airborne frames (ascending → descending transition); delta must be positive
- `projectile_velocity_x`: `mean(|velocity_x|)` for projectile entries in_flight
- Convert each to per-second: `value / (16.768 / 1000)`
- Validate: sample_count ≥ 10; value > 0 for all constants
- Return `CalibrationResult` dataclass with 4 `CalibrationConstant` entries
- **Files affected:** `apps/mame-harness/physics_calibrator.py`

### ST2 — YAML output

- `validate_artifact`-style guardrail: call `ensure_public_output_path` + `ensure_no_private_paths` on payload
- Create `specs/calibration/` if absent
- Write YAML with `schema_version`, `source_trace`, `ms_per_frame`, and one entry per constant
- **Files affected:** `apps/mame-harness/physics_calibrator.py`, `specs/calibration/gng_physics_calibration.yaml`

### ST3 — gng_abstract_mechanics.yaml update

- For each of the 4 `calibration: pending` fields: replace with `calibrated_value: <measured>` and `sample_count: <n>`
- Update top-level `calibration_status` comment to reflect T11.3 completion
- **Files affected:** `specs/mechanics/gng_abstract_mechanics.yaml`

### ST4 — PhysicsSystem.ts update

- Replace hardcoded config in `GameLoop` or wherever defaults are set
- Source values from calibration YAML (or hardcode the measured numeric values with a comment referencing `gng_physics_calibration.yaml`)
- Note coordinate system: trace `velocity_y` negative = ascending; PhysicsSystem `velocity.y` positive = ascending → `jumpVelocity = |measured_vy_start|`
- **Files affected:** `apps/rn-prototype/src/engine/PhysicsSystem.ts` or `apps/rn-prototype/src/engine/GameLoop.ts`

### ST5 — Tests

- `test_calibrate_returns_four_constants` — all 4 keys present
- `test_sample_counts_meet_minimum` — all sample_count ≥ 10
- `test_values_are_positive` — all values > 0
- `test_calibration_yaml_passes_guardrails` — `ensure_no_private_paths` passes on output
- `test_calibration_yaml_exists_after_write` — file on disk

TypeScript tests (in `engine.test.ts`):
- `test_physics_system_does_not_use_hardcoded_gravity` — gravity !== 9.8
- `test_physics_system_does_not_use_hardcoded_move_speed` — moveSpeed !== 3
- `test_physics_system_does_not_use_hardcoded_jump_velocity` — jumpVelocity !== 6

- **Files affected:** `apps/mame-harness/tests/test_physics_calibrator.py`, `apps/rn-prototype/tests/engine.test.ts`
