# T10.9.3 — Cyclops Boss Signature Calibration

## Status

🔲 Planned — awaiting parent-task approval.

## Parent Task

[T10.9 — Boss and Devil Tracking](./T10.9-boss-and-devil-tracking.md)

## Objective

Calibrate an `EnemySignature` for the stage-1 boss (cyclops / "Big Men"), entity type `boss_a`, using the ADR-019 picker pattern. The cyclops is the largest enemy sprite in stage 1, moves slowly, and typically appears as two simultaneous instances in the standard boss layout.

## Scope

- Use the picker tooling extended in T10.9.2 to surface candidate cyclops clusters from post-scroll boss-encounter frames.
- If existing evidence lacks coherent boss footage, perform a short complementary capture (`run_t10_9_boss`) with the operator driving Arthur to the boss encounter intentionally, then dying once.
- Operator validates ≥ 3 cyclops candidate clusters.
- Calibrate bounds: large height (significantly above zombi/crow/Arremer), narrow `max_frame_jump_px` (slow motion), low `center_y` variance (ground-level only).
- Append `boss_a` section to `specs/calibration/gng_enemy_signatures.yaml`.
- Regression test:
  - Calibrator rejects cyclops clusters smaller than zombi maximum height (sanity check that boss truly dominates the size range).

## Out of Scope

- Boss behavior modelling (movement patterns, attack timing) — derived from the regenerated trace by T12.
- Multi-cyclops occlusion handling — accepted limitation; `gap_tolerance_frames` covers brief merges.
- Boss HP, phases, or death animation — not signature-relevant.

## Acceptance Criteria

1. If `run_t10_4_01` lacks boss footage, `run_t10_9_boss` is captured and stored under `evidence/private/run_t10_9_boss/` (gitignored).
2. Picker surfaces candidate cyclops clusters with frame ranges; stdout contains no PNG paths.
3. Operator has accepted ≥ 3 clusters.
4. `specs/calibration/gng_enemy_signatures.yaml` contains a `boss_a` section with:
   - `height_min` strictly greater than the maximum of any prior enemy `height_max`.
   - `center_y_min/max` covering ground level only.
   - `aspect_ratio` allowing vertical bias.
   - `max_frame_jump_px` ≤ 12 (cyclops moves slowly).
   - `gap_tolerance_frames` ≥ 3.
   - `sample_count`, `calibration_source`, `calibration_method`.
5. YAML passes `ensure_no_private_paths`.
6. Regression test rejects clusters with `height_max < zombi.height_max` from being classified as boss.
