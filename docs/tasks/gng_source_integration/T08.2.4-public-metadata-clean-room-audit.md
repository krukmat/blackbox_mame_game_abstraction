# T08.2.4 - Public Metadata Clean-room Audit

## Status

✅ Done — 2026-05-13

## Files and Lines Affected

Read-only audit of `specs/run_metadata.json`.

## Purpose

After a real capture (T08.2.2), verify that `specs/run_metadata.json` contains no absolute paths, no ROM paths, no frame paths — only `private://` URIs and safe redacted tokens. This is the clean-room boundary gate for the public output.

## Reference Reasoning

`Low`

Reasoning basis:

- the redaction logic is already implemented and tested (T05)
- this task is a pass/fail audit, not an implementation task
- ADR-002 and ADR-003 define the exact rules being checked

## Scope

- read `specs/run_metadata.json` after the real run
- verify no field contains an absolute path (`/Users/`, `/home/`, `C:\`)
- verify all evidence directory references use `private://` URIs
- verify `runner_status`, `preflight.ok`, `preflight.driver` have the expected values

## Out of Scope

- modifying any source file
- auditing private evidence contents (T08.2.3)
- changing redaction rules

## Inputs

- `specs/run_metadata.json` written by the real run in T08.2.2
- `run_id` from T08.2.2

## Deliverables

- pass/fail result for each metadata condition
- full redacted JSON for the operator record

## Dependencies

- `T08.2.2`

## Acceptance Criteria

| # | Condition | Result |
|---|-----------|--------|
| 1 | No field in `command[]` contains `/Users/`, `/home/`, or `C:\` | ✅ Pass — rom-path redacted as `<redacted:path>` |
| 2 | All `evidence/private` refs use `private://` URI form | ✅ Pass — logs, states, frames, video all use `private://ed0cb0ac19a4/...` |
| 3 | `runner_status == "success"` | ✅ Pass |
| 4 | `preflight.ok == true` | ✅ Pass — MAME 0.287 |
| 5 | `preflight.profile_id == "gng"` | ✅ Pass |
| 6 | `preflight.driver == "gngb"` | ✅ Pass |
