# T30.1 — Execution environment + GNG savestate anchor

## Objective

Stand up a verified, working execution environment on the current machine and create a private
GNG savestate at the "Arthur controllable" moment. This is the mandatory gate before any
capture or calibration task can run. Two hard deliverables, each with a verifiable check:

1. `cli.py doctor` exits green AND the full pytest suite passes (31 test files, venv).
2. A private MAME savestate file exists at `evidence/private/savestates/gng_controllable.sta`.

## Why this is the real blocker

The environment does not exist: no venv, no Python 3.11, no MAME binary, no ffmpeg, no `.env`.
Every T20.x task is "operator step pending" because of this. Nothing downstream can be verified
without clearing this gate.

## Scope

- Install Python 3.11 via brew.
- Create and populate the venv at `apps/mame-harness/.venv/`.
- Install MAME 0.288 via brew.
- Install ffmpeg via brew.
- Create `.env` from `.env.example` with real local values.
- Run `cli.py doctor` and confirm it exits green.
- Run the full pytest suite and confirm all tests pass.
- Launch MAME with the boot plan, let the autoboot reach the controllable state, save state,
  confirm the savestate file exists in the private evidence directory.

## Out of scope

- Any capture beyond saving the controllable state.
- Any calibration or schema work (T30.2–T30.5).
- Any public artifact changes.

## Dependencies

- T30.0a–c ✅ (ADR-028 recorded — this task operates under the new architecture).
- The operator must have `gng.zip` in a local private ROM directory.

## Steps (exact commands, in order)

All commands run from the repo root `/Users/matias/blackbox_mame_game_abstraction/`.

### Step 1 — Install Python 3.11 and binaries

```bash
brew install python@3.11
brew install mame
brew install ffmpeg
```

Verify:
```bash
/opt/homebrew/bin/python3.11 --version   # expect: Python 3.11.x
mame --version                           # expect: MAME 0.288 (or 0.28x)
ffmpeg -version                          # expect: ffmpeg version 8.x
```

### Step 2 — Create the venv

```bash
/opt/homebrew/bin/python3.11 -m venv apps/mame-harness/.venv
apps/mame-harness/.venv/bin/pip install --upgrade pip
apps/mame-harness/.venv/bin/pip install -e "apps/mame-harness[dev]" 2>/dev/null || \
  apps/mame-harness/.venv/bin/pip install PyYAML Pillow "opencv-python-headless>=4.0" pytest
```

Verify:
```bash
apps/mame-harness/.venv/bin/python --version   # must be 3.11.x
```

### Step 3 — Create .env

```bash
cp .env.example .env
```

Edit `.env` and fill in:
- `BLACKBOX_MAME_BINARY` — output of `command -v mame`
- `BLACKBOX_FFMPEG_BINARY` — output of `command -v ffmpeg`
- `BLACKBOX_ROM_PATH` — absolute path to the directory containing `gng.zip`

Leave all other values as-is from `.env.example`.

### Step 4 — Run doctor

```bash
apps/mame-harness/.venv/bin/python apps/mame-harness/cli.py doctor
```

Expected: green output, exit code 0. If any check fails, fix it before continuing.

### Step 5 — Run the full test suite

```bash
apps/mame-harness/.venv/bin/pytest -q
```

Expected: all tests pass (31 test files). If any test fails, report the failure and stop —
do not proceed to the savestate step while tests are broken.

### Step 6 — Create the GNG controllable savestate

Create the private savestates directory:
```bash
mkdir -p evidence/private/savestates
```

Launch MAME with the autoboot plan and save state at the controllable moment:
```bash
./scripts/launch_manual_capture_autoboot.sh savestate_01
```

Wait for the autoboot to complete (~25 seconds). When Arthur appears on screen (frame ~1505),
immediately press **F7** in the MAME window to save state (MAME default savestate key), or
use the MAME UI menu → File → Save State. Then close MAME.

MAME writes savestates to its internal cfg directory by default. Copy the savestate file to
the private evidence directory:
```bash
# MAME savestate location varies; check ~/.mame/ or the dir MAME reports.
# Copy to the canonical private path:
cp <mame_savestate_path>/gngb.sta evidence/private/savestates/gng_controllable.sta
```

Verify:
```bash
ls -lh evidence/private/savestates/gng_controllable.sta
```

Expected: file exists, size > 0.

### Step 7 — Record the MAME binary path

Add to `.env`:
```
BLACKBOX_SAVESTATE_PATH=evidence/private/savestates/gng_controllable.sta
```
