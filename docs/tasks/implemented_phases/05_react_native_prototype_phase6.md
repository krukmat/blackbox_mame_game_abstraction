# Prompt — React Native Prototype Phase 6

Implement Phase 6: React Native prototype scaffold.

## Goal

Create a spec-driven React Native game prototype that can consume abstract mechanics and entity specs generated by the black-box framework.

## Use

```text
React Native
React Native Skia for rendering
TypeScript
deterministic game loop
simple virtual controls
```

## Scope

### 1. Create `src/engine`

```text
GameLoop.ts
TimeStep.ts
SceneManager.ts
PhysicsSystem.ts
CollisionSystem.ts
EventBus.ts
```

### 2. Create `src/entities`

```text
Entity.ts
Player.ts
Enemy.ts
Projectile.ts
Pickup.ts
Hazard.ts
```

### 3. Create `src/rendering`

```text
SkiaRenderer.tsx
Camera.ts
SpriteAnimator.ts
DebugOverlay.tsx
```

### 4. Create `src/input`

```text
VirtualGamepad.tsx
InputState.ts
```

### 5. Create `src/specs`

```text
mechanics.generated.sample.json
entities.generated.sample.json
```

### 6. Implement a minimal playable scene

Requirements:

```text
rectangle/capsule placeholder entities only
no copyrighted assets
player movement
jump
one patrolling enemy
collision detection
debug overlay
```

### 7. Add tests where practical

Add tests for:

```text
physics deterministic step
collision outcomes
spec loading
```

## Constraints

- Do not include original assets.
- Use placeholder geometric shapes only.
- Keep code clean and mobile-oriented.
