# T12.8 — Originality and Design-Intent Validation Gate

## Status

🔲 Planned

## Objective

Add automated validation cases that verify the Signal Garden vertical slice is clean-room safe and design-complete. This is the exit gate for the entire T12 phase.

## Scope

- Author `packages/validation/tests/test_signal_garden_originality.py` with validation cases covering:
  - **Mechanics compliance**: trace entries used in episode data are abstract (no pixel coordinates, no source entity names)
  - **Encounter grammar conformance**: every scene recipe references only roles defined in the encounter grammar
  - **Scene divergence**: every scene recipe has a non-empty `divergence_note`
  - **Naming safety**: no recipe, scene, encounter pattern, or progression entry contains a known source name (define a blocklist from T12.2 naming rules)
  - **Public-output guardrails**: all T12 artifacts pass `ensure_public_output_path` and `ensure_no_private_paths`
  - **Asset recipe completeness**: every encounter role used in a scene recipe has a corresponding enriched asset recipe from T12.6
  - **Human review flag**: `human_review_required: true` is present in every asset recipe
- Verify all T12 artifacts validate against their respective schemas
- Run full Python and TypeScript test suites and confirm no regressions
- Document validation results in `## Validation Evidence` section

## Out of Scope

- Pixel comparison against source screenshots (forbidden by ADR-008)
- Automated legal determination
- Rendering tests or screenshot comparison of the prototype

## Dependencies

- T12.7 complete (vertical slice must exist for full validation)
- All T12.3–T12.6 artifacts must exist

## Effort

`M`

## Reasoning Grade

`High` — the blocklist must be carefully sourced from T12.2 naming rules; schema cross-references span multiple files; false negatives here carry clean-room risk

## Recommended Model

`Sonnet`

## Acceptance Criteria

- `test_signal_garden_originality.py` exists and covers all six validation categories above
- All validation tests pass
- No T12 artifact fails a guardrail check
- No T12 artifact references source names from the T12.2 naming rules blocklist
- Full Python and TypeScript test suites pass
- `## Validation Evidence` section is populated with per-category pass/fail results
