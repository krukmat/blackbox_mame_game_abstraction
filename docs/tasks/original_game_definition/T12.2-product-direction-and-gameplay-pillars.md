# T12.2 — Product Direction and Gameplay Pillars

## Status

🔲 Planned

## Objective

Define the original game concept for Signal Garden: audience, gameplay pillars, core loop, player verbs, tone, naming rules, and explicit anti-source-identity constraints. This is the design brief that all subsequent T12 tasks consume.

## Scope

- Author `specs/game/signal_garden_design_brief.yaml` with:
  - `game_title`: Signal Garden
  - `audience`: target player profile (mobile, compact sessions)
  - `pillars`: 3–5 named design pillars (e.g., "committed momentum", "readable timing pressure", "pulse-based interaction")
  - `core_loop`: one-paragraph description of the play cycle
  - `player_verbs`: list of abstract actions the player performs (derived from T12.1 affordances — no source names)
  - `session_length_target_minutes`: target mobile session length
  - `tone`: visual and narrative tone (must be independent of source identity)
  - `naming_rules`: constraints on entity, zone, and level naming (must exclude source names, source enemy names, source stage labels)
  - `anti_source_constraints`: explicit list of what Signal Garden must NOT be (visual style, encounter pacing, character framing)
  - `mechanic_inputs`: references to T12.1 affordances used — not original mechanics, not source-specific descriptions
- Verify `ensure_no_private_paths` passes
- Verify brief contains no source names, stage names, enemy names, or visual callbacks

## Out of Scope

- Encounter grammar (T12.3)
- Scene recipes (T12.4)
- Asset generation
- Final branding, monetization, narrative

## Dependencies

- T12.1 (affordance map required as design input)

## Effort

`M`

## Reasoning Grade

`High` — the brief must be original enough to pass originality validation while being specific enough to guide T12.3–T12.7 without contradiction

## Recommended Model

`Sonnet`

## Acceptance Criteria

- `specs/game/signal_garden_design_brief.yaml` exists and is non-empty
- All five required fields (pillars, core_loop, player_verbs, naming_rules, anti_source_constraints) are present
- No field contains source names, source stage labels, or source enemy names
- `ensure_no_private_paths` passes
- Brief is specific enough that T12.3 can write encounter grammar rules without additional design decisions
