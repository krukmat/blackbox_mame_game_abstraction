# T12.1 — Public Mechanics Capability Review

## Status

🔲 Planned

## Objective

Classify which abstract mechanics from `gng_abstract_mechanics.yaml` and `gng_episodes.json` can safely inform the Signal Garden game design, and which carry clone risk. Produce a structured design affordance map that T12.2 uses as input.

## Scope

- Read `gng_abstract_mechanics.yaml` and list every mechanic (locomotion, jump arc, projectile, gravity, entity events)
- For each mechanic, classify:
  - **Safe affordance**: abstract capability that can be reused without cloning (e.g., "committed jump arc", "discrete move speed", "projectile travel time")
  - **Clone risk**: expressive content or source-specific structure to avoid (e.g., source stage layout, source enemy names, exact spawn timing sequences)
  - **Design freedom**: where Signal Garden must diverge (e.g., theme, visual language, encounter order, narrative framing)
- Review `gng_episodes.json` episode structure for what can be used as a design-pattern input (timing windows, encounter shapes) vs what must be re-authored
- Output: `specs/game/gng_mechanics_affordance_map.yaml`
  - fields: `mechanic_id`, `safe_affordance`, `clone_risk`, `design_freedom_note`, `signal_garden_verb`
- Verify output passes `ensure_no_private_paths`

## Out of Scope

- Signal Garden game design decisions (T12.2)
- Encounter grammar (T12.3)
- Asset recipes (T12.6)
- Any output that encodes source level structure, source names, or visual identity

## Dependencies

- T12.0 (ADRs and phase plan must be in place)
- T10.4 (calibrated abstract mechanics required as input)
- T11 (episode format must exist to review)

## Effort

`S`

## Reasoning Grade

`High` — distinguishing safe affordance from clone risk requires careful reading of ADR-010 and ADR-011; a wrong classification here propagates through all downstream T12 tasks

## Recommended Model

`Sonnet`

## Acceptance Criteria

- `specs/game/gng_mechanics_affordance_map.yaml` exists
- Every mechanic in `gng_abstract_mechanics.yaml` has an entry
- No entry encodes source names, level labels, enemy names, or exact spawn sequences
- `ensure_no_private_paths` passes
- Another agent can proceed to T12.2 using only this file and `gng_abstract_mechanics.yaml` as inputs
