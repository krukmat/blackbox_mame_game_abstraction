# T12.6 — Theme Translation and Asset Recipe Enrichment

## Status

🔲 Planned

## Objective

Align existing public asset recipes with the Signal Garden product direction. Extend recipe entries with Signal Garden role language, shape/readability requirements, and varied theme prompts. All ADR-007 prohibited similarity rules and `human_review_required: true` must remain intact.

## Scope

- Read existing recipes under `specs/assets/` (entity archetypes)
- For each recipe, add or update:
  - `signal_garden_role`: Signal Garden-specific role name (no source entity names)
  - `shape_notes`: geometric readability requirement for mobile (e.g., "distinct silhouette at 32×32 equivalent", "high contrast edge")
  - `theme_variants`: ≥ 3 varied original theme suggestions — must differ per entity, not be identical boilerplate
  - Verify the five ADR-007 prohibited similarity rules are present and non-trivial for each recipe
  - `human_review_required: true` must remain on every recipe
- Author new recipes for any encounter roles from T12.3 that lack a corresponding recipe
- Verify all recipes pass `ensure_no_private_paths`
- Verify no recipe references original sprite paths, screenshot crops, or source visual descriptions

## Out of Scope

- Generating images or sprites
- Image-to-image workflows
- Final branding decisions

## Dependencies

- T12.2 (design brief defines tone and naming rules for role language)
- T12.3 (encounter grammar defines roles that need recipe coverage)
- T12.5 (progression model identifies which roles appear in the vertical slice — prioritize those)

## Effort

`M`

## Reasoning Grade

`High` — ADR-007 compliance is legally load-bearing; `suggested_new_theme_variants` must be varied (current Known Gap: they are hardcoded identically); theme language must map to Signal Garden identity, not source identity

## Recommended Model

`Sonnet`

## Acceptance Criteria

- Every encounter role from T12.3 has a corresponding asset recipe
- All recipes have `signal_garden_role`, `shape_notes`, and ≥ 3 distinct `theme_variants`
- All five ADR-007 prohibited similarity rules are present and non-trivial in every recipe
- `human_review_required: true` is present on every recipe
- No recipe encodes original sprite paths, image crop coordinates, or source visual descriptions
- `ensure_no_private_paths` passes on all recipe files
