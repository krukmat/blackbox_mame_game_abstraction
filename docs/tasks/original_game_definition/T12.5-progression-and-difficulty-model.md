# T12.5 — Progression and Difficulty Model

## Status

🔲 Planned

## Objective

Define how Signal Garden scenes ramp into a playable vertical slice. Specify difficulty bands, encounter sequencing, failure/retry assumptions, timing pressure curves, and mobile session length targets.

## Scope

- Author `packages/schemas/progression.schema.json` — JSON Schema for progression YAML
- Author `specs/progression/signal_garden_progression.yaml` with:
  - `difficulty_bands`: named bands (e.g., intro, mid, peak) each with:
    - `encounter_pattern_refs`: references to T12.3 grammar patterns allowed in this band
    - `timing_pressure_modifier`: abstract scalar (1.0 = baseline from T12.1 affordances)
    - `failure_tolerance`: retry model (immediate, checkpoint, session-end)
  - `scene_sequence`: ordered list of scene recipe IDs (from T12.4) for the vertical slice
  - `session_length_notes`: how many scenes fit in target mobile session length (from T12.2 brief)
  - `tuning_ranges`: configurable parameters for playtesting (timing window tolerance, gap size, etc.)
- Validate `scene_sequence` entries against T12.4 recipe IDs
- Verify progression model does not reproduce source stage order or source pacing labels
- Verify `ensure_no_private_paths` passes

## Out of Scope

- Full campaign design
- Boss encounters
- Source stage parity
- Procedural level generation

## Dependencies

- T12.4 (scene recipes must exist — progression references recipe IDs)
- T12.2 (design brief defines session length target and tone)

## Effort

`M`

## Reasoning Grade

`Medium` — progression ordering is original design work; timing modifiers are abstract scalars (not source frame counts); main risk is accidentally encoding source stage order

## Recommended Model

`Sonnet`

## Acceptance Criteria

- `packages/schemas/progression.schema.json` validates `specs/progression/signal_garden_progression.yaml` without errors
- `scene_sequence` references only T12.4 recipe IDs
- Difficulty bands include tuning ranges that allow playtesting adjustment
- No band name, scene label, or sequencing note uses source stage names or source pacing terminology
- `ensure_no_private_paths` passes
