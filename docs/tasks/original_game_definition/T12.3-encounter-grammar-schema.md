# T12.3 — Encounter Grammar Schema

## Status

🔲 Planned

## Objective

Define how abstract roles combine into original encounter patterns for Signal Garden. Produce a schema and example grammar that specifies role-based encounter composition without encoding source level structure.

## Scope

- Author `packages/schemas/encounter_grammar.schema.json` — JSON Schema for encounter grammar YAML
- Author `specs/encounters/encounter_grammar.yaml` with:
  - `roles`: abstract entity roles (traversal_blocker, patroller, airborne_threat, pulse_target, safe_zone, timing_window)
  - `encounter_patterns`: named patterns combining roles (e.g., "gauntlet", "pressure_wave", "safe_passage")
  - Each pattern must include:
    - `roles_required`: list of abstract roles
    - `timing_band`: frame-count range (from T12.1 affordances, not source-specific values)
    - `divergence_constraint`: at least one rule specifying how this pattern must differ from source encounters (required field)
    - `signal_garden_name`: Signal Garden-specific label for the pattern
- Include ≥ 5 distinct encounter patterns
- Verify schema validates all example patterns
- Verify `ensure_no_private_paths` passes

## Out of Scope

- Scene recipes (T12.4) — encounter grammar defines roles and patterns, not spatial layout
- Exact source encounter reproduction
- Procedural generation engine
- Real asset generation

## Dependencies

- T12.2 (design brief defines player verbs and pillars that encounter roles must serve)

## Effort

`M`

## Reasoning Grade

`High` — encounter pattern names and role labels must be original; divergence constraints are legally load-bearing; every pattern must be verifiable against ADR-011

## Recommended Model

`Sonnet`

## Acceptance Criteria

- `packages/schemas/encounter_grammar.schema.json` validates `specs/encounters/encounter_grammar.yaml` without errors
- ≥ 5 encounter patterns exist, each with `roles_required`, `timing_band`, `divergence_constraint`, and `signal_garden_name`
- No pattern name, role name, or timing value encodes source level labels, source enemy names, or exact source spawn sequences
- `ensure_no_private_paths` passes on both files
- A T12.4 agent can write scene recipes using only encounter grammar roles as input
