# T20.3 — Experiment-Plan Schema + GNG Isolation Battery (ADR-024)

## Objective
Define a declarative "experiment plan" format and author a battery of deterministic GNG input
plans, each isolating exactly one mechanic so its constant can be measured without human
candidate picking.

## Scope
- Add an experiment-plan schema in `packages/schemas/` extending the input-plan format with:
  `experiment_id`, `isolated_variable`, `measurement_window` (frame range), and
  `expected_signal` (e.g., monotone x, parabolic y).
- Author the GNG battery as input plans under `plans/sequences/` (or `plans/generated/`):
  - `idle_baseline` — no input N frames (ground level, noise floor).
  - `walk_right` — hold right N frames (isolates `locomotion_velocity_x`).
  - `jump_in_place` — single jump, no horizontal input (isolates `jump_velocity_y`, `gravity`).
  - `fire_stationary` — single fire, no movement (isolates `projectile_velocity_x`,
    `spawn_delay`).
- Author `docs/adr/ADR-024-designed-experiment-calibration.md`: designed isolation experiments
  are the default calibration method; ADR-019 human-picker pattern is demoted to the fallback
  for non-isolatable constants.

## Out of scope
- The calibrator that consumes these experiments (T20.4).
- Capturing the runs (operator action at execution time).

## Dependencies
T20.1 (experiments rely on ground-truth input timeline).

## Reasoning grade
Medium — designing experiments that genuinely isolate one variable each.

## Effort grade
Medium.

## Acceptance criteria
- Experiment-plan schema validates each battery plan.
- Each battery plan isolates exactly one variable with a defined measurement window.
- ADR-024 authored; ADR-019 reframed as fallback in its text and indices updated.
- Plans are deterministic (ADR-009): same plan → same frame sequence.
