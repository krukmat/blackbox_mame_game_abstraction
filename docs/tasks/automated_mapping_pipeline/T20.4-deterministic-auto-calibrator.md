# T20.4 — Deterministic Auto-Calibrator (No Human Picker)

## Objective
Compute the standard physics constants directly from the isolation-experiment captures
(T20.3) via closed-form/regression measurement, producing the calibration YAML with **zero
human picks** for the standard constants.

## Scope
- A calibrator that, per experiment, selects the measurement window and computes:
  - `locomotion_velocity_x` = Δx/Δframes over the `walk_right` plateau.
  - `jump_velocity_y`, `gravity` = least-squares fit of the parabolic y(t) over `jump_in_place`.
  - `projectile_velocity_x` = slope of projectile x(t); `spawn_delay` = frames from `fire`
    event to first projectile appearance.
- Write `specs/calibration/gng_physics_calibration.yaml` deterministically; include
  per-constant `sample_count`, `r_squared`/residual, and `experiment_id` provenance.
- Auto-flag low-fit results for optional ADR-019 human fallback rather than silently
  accepting them.
- Keep outputs schema-compatible with the current mechanics YAML sync.

## Out of scope
- Memory-sourced calibration (T20.6).
- The mechanics YAML manual sync step (keep existing behavior; can be a follow-up).

## Dependencies
T20.3 (and benefits from T20.2 ground-truth events for `fire`/`spawn_delay`).

## Reasoning grade
High — measurement correctness directly affects public output; must avoid the ADR-019
`t_peak`-off-by-40× failure mode.

## Effort grade
Medium.

## Acceptance criteria
- Running the battery yields all four constants with no human candidate selection.
- Calibration is reproducible: same captures → identical values.
- Each constant carries provenance (experiment_id, window, fit quality).
- A physical consistency check passes (e.g., predicted `t_peak` matches observed within
  tolerance), explicitly closing the ADR-019 failure mode.
- Tests on synthetic motion verify closed-form/regression correctness.

## Recommended model
Opus.
