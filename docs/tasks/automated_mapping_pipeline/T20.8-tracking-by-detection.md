# T20.8 — Generic Motion Segmentation + Tracking-by-Detection (ADR-025 pt.2)

## Objective
Replace per-entity hand-calibrated signatures (ADR-012/021) with generic motion segmentation
plus a tracking-by-detection tracker (SORT/ByteTrack-style) that assigns persistent IDs
without per-enemy calibration.

## Scope
- Generic per-frame detection of moving blobs on scroll-compensated frames (T20.7).
- A multi-object tracker maintaining persistent IDs across frames via IoU/motion association
  (no per-entity geometric/color signature required).
- Entity-type assignment downgraded to coarse, data-driven classes (size/motion clusters),
  feeding `entity_type` without copyright names.
- Author `docs/adr/ADR-025-modern-vision-backend.md` (part 2: tracking-by-detection); state how
  it supersedes ADR-012/021 hand-signature calibration.

## Out of scope
- VLM semantic labeling (T20.9 refines coarse classes into archetypes).
- Memory tap (T20.5).

## Dependencies
T20.7.

## Reasoning grade
High — multi-object tracking correctness, persistent identity across occlusion/scroll.

## Effort grade
High.

## Acceptance criteria
- Persistent IDs survive a multi-entity fixture across frames without per-entity signatures.
- ID-switch rate under a defined threshold on the GNG stage-1 fixture.
- `entity_id`/`entity_type` carry no copyright proper nouns (ADR-006/clean-room).
- ADR-025 (pt.2) authored; ADR-012/021 reframed accordingly; indices/vault updated.
- Trace schema remains stable for downstream consumers.

## Recommended model
Opus.
