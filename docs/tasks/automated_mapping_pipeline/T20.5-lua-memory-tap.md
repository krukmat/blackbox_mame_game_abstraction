# T20.5 — Lua Memory-Tap → Private Numeric State Timeline (ADR-026 impl)

## Objective
If ADR-026 is Accepted, read entity position/state from MAME RAM via Lua using community
cheat-database addresses, producing a private, noise-free numeric state timeline.

## Scope
- A Lua memory-reader (in `scripts/mame_autoboot.lua` or a sibling) that, each frame, reads a
  configured address set via `manager.machine.devices[":maincpu"].spaces["program"]:read_u8/u16`.
- Address set provided by an external, cited config (community cheat DB) — never hardcoded from
  ROM disassembly; stored as a private/local config, not committed.
- Write `evidence/private/run_<id>/logs/state_timeline.json`: per-frame numeric
  `{entity, x, y, state_flags}` — numbers only.
- Guardrail tests: addresses and raw values never reach any public artifact; only derived
  abstract numbers do.

## Out of scope
- Using the timeline for calibration (T20.6).
- Any address discovery/disassembly of the ROM (prohibited).

## Dependencies
T20.0 = Accepted.

## Reasoning grade
High — clean-room boundary execution; address provenance discipline.

## Effort grade
Medium.

## Acceptance criteria
- With a valid address config, `state_timeline.json` contains frame-accurate numeric state.
- No addresses, no ROM-derived strings, no raw values in any public artifact (test-enforced).
- Address config is local/private and documented as community-cited, not ROM-derived.
- Absent/invalid config degrades gracefully (no crash; pipeline falls back to vision).

## Recommended model
Opus.
