# T20.6 — Memory-Sourced Calibration + CV Cross-Check Report

## Objective
Use the private numeric state timeline (T20.5) as a high-accuracy positional source for
calibration and produce a consistency report comparing memory-sourced vs CV-sourced values.

## Scope
- Feed `state_timeline.json` positions into the auto-calibrator (T20.4) as an alternative
  positional source.
- Emit a private cross-check report: per-constant memory vs CV deltas, agreement bands.
- Promote the memory-sourced value to the public calibration YAML when agreement is within
  tolerance; otherwise flag for review.

## Out of scope
- Replacing the vision pipeline (memory is an additional source, not a deletion).

## Dependencies
T20.5, T20.4.

## Reasoning grade
Medium — comparison logic and promotion policy.

## Effort grade
Medium.

## Acceptance criteria
- Calibration can run from the memory source and from CV; both are reproducible.
- A cross-check report quantifies agreement; out-of-band constants are flagged not silently
  promoted.
- Public output still numbers-only; report stays private.

## Recommended model
Sonnet.

## Reference documents
- `docs/plans/automated_mapping_pipeline_plan.md`
- ADR-026, ADR-024, ADR-008
- `apps/mame-harness/physics_calibrator.py`, `specs/calibration/`

"Feed the memory state_timeline into the T20.4 calibrator as an alternate positional source,
and emit a private memory-vs-CV consistency report. Promote memory values to public
calibration only within tolerance; flag disagreements. Keep public output numbers-only."
